# Retro Cabinet - a classic games platform

## Classic-style games

- Falling Blocks
- Maze Chase
- Alien Attack
- Snake
- Brick Breaker
- Space Rocks
- Jewel Drop
- Frog Crossing
- Table Tennis

## Bonus games

One-time reward.
"Unlocked" by reaching specific conditions or the reward itself.

- Match Four
- Dots & Boxes
- Wari
- Minefield
- Code Breaker
- Matching Pairs
- Naval Battle
- Alien Smash
- Shut the Box

## Quality of life

- Configurable options.
- Auto-save on pause or when switching tabs / applications.
- Keeps track of best scores with their dates.
- Virtual controls on touch devices.
