# Retro Cabinet - a classic games platform

## Classic games 

- Tetris
- Pacman
- Space Invaders
- Snake
- Arkanoid
- Asteroids
- Columns
- Frogger
- Pong

## Quality of life

- Configurable options.
- Auto-save on pause or when switching tabs / applications.
- Keeps track of best scores with their dates.
- Virtual controls on touch devices.
